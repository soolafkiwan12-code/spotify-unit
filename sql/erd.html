تصميم ERD — مشروع Spotify

مخطط الكيانات والعلاقات لقاعدة بيانات منصة استماع موسيقى: مستخدمون، فنانون، ألبومات، أغاني، قوائم تشغيل، إعجابات.

PK = Primary KeyFK = Foreign Key

roles

  • id PK
  • name
  • description

users

  • id PK
  • role_id FK → roles
  • name, email, password
  • created_at

artists

  • id PK
  • name, country, bio

albums

  • id PK
  • artist_id FK → artists
  • title, release_year, cover_image

tracks

  • id PK
  • album_id FK → albums
  • title, duration_seconds, genre

playlists

  • id PK
  • user_id FK → users
  • name, is_public

playlist_track

  • playlist_id + track_id PK
  • playlist_id FK
  • track_id FK
  • position

likes

  • user_id + track_id PK
  • user_id FK → users
  • track_id FK → tracks

contact_messages

  • id PK
  • user_id FK → users (nullable)
  • name, email, message

العلاقات

  • roles 1 : N users — لكل دور عدة مستخدمين.
  • artists 1 : N albums — الفنان يملك عدة ألبومات.
  • albums 1 : N tracks — الألبوم يحتوي عدة أغاني.
  • users 1 : N playlists — المستخدم ينشئ عدة قوائم.
  • playlists N : M tracks عبر playlist_track.
  • users N : M tracks عبر likes.
  • users 1 : N contact_messages (اختياري).

Mermaid ERD

erDiagram
  ROLES ||--o{ USERS : has
  USERS ||--o{ PLAYLISTS : creates
  USERS ||--o{ LIKES : likes
  USERS ||--o{ CONTACT_MESSAGES : sends
  ARTISTS ||--o{ ALBUMS : records
  ALBUMS ||--o{ TRACKS : contains
  PLAYLISTS ||--o{ PLAYLIST_TRACK : includes
  TRACKS ||--o{ PLAYLIST_TRACK : listed_in
  TRACKS ||--o{ LIKES : liked_by

  ROLES { tinyint id PK; varchar name }
  USERS { int id PK; tinyint role_id FK; varchar email }
  ARTISTS { int id PK; varchar name }
  ALBUMS { int id PK; int artist_id FK; varchar title }
  TRACKS { int id PK; int album_id FK; varchar title }
  PLAYLISTS { int id PK; int user_id FK; varchar name }
  PLAYLIST_TRACK { int playlist_id PK_FK; int track_id PK_FK }
  LIKES { int user_id PK_FK; int track_id PK_FK }
