# PHP 8 Admin

1. ثبّت XAMPP (PHP 8 + MySQL).
2. من phpMyAdmin نفّذ بالترتيب:
   - `sql/01_schema.sql`
   - `sql/02_seed.sql`
3. عدّل `php/config.php` إذا كانت كلمة مرور MySQL ليست فارغة.
4. افتح `http://localhost/spotify/php/login.php`
