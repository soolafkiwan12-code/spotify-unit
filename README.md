# Spotify Clone — فكرة المشروع

المشروع نسخة تعليمية من منصة **Spotify**: موقع استماع موسيقى يعرض ألبومات وفنانين ومشغّل أغاني، مع حسابات مستخدمين وصلاحيات، وقاعدة بيانات تربط الأغاني بالألبومات والفنانين وقوائم التشغيل.

الهدف من التدريب: بناء نفس الفكرة على طبقات التقنية المطلوبة في الدورة، من الواجهة الثابتة حتى لوحة تحكم Vue مربوطة بـ Laravel API.

## مجلدات المشروع

| المجلد | ماذا يغطي |
|---|---|
| `index.html` + `styles.css` + `js/app.js` | HTML / CSS / JavaScript |
| `sql/` | الجداول، PK/FK، العلاقات، CRUD، Joins، ERD |
| `php/` | PHP 8: تسجيل دخول، Sessions، صلاحيات، بحث، إضافة/تعديل/حذف |
| `laravel/` | Routes, Controllers, Blade, Migrations, Models, Eloquent, Validation, Auth, Roles, REST API, Sanctum |
| `vue-dashboard/` | Vue 3 Composition API Dashboard + ربط REST API |
